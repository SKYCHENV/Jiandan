# 剪蛋

[简体中文](README.md) | [English](README_EN.md)

<img src="assets/brand/jiandan.png" alt="剪蛋" width="160">

**简单复制到剪映。** 复制或截图一张图片，在剪映素材页按 `Ctrl+V`，剪蛋会把本次图片导入素材区并自动选中预览，不添加到时间线。

## 为什么有剪蛋

剪映不支持把刚刚截好的图片直接粘贴进素材区。

原本为了使用一张截图，你可能要先在网上保存图片，或者把截图粘贴到聊天窗口，再保存到本地，最后拖进剪映。明明图片已经在剪贴板里，却还要绕一大圈。

所以有了剪蛋：截图或复制图片后，回到剪映按下 `Ctrl+V`，图片就会进入素材区并自动选中预览。少一次保存，少一次寻找，也不需要拖动文件。

## 环境

- Windows 10 或 Windows 11
- Python 3.10 或更高版本
- 剪映专业版

## 启动

双击 `run.bat`。

首次启动会在项目目录创建 `.venv` 并安装依赖，完成后自动打开状态窗口。以后再次双击会直接启动；如果剪蛋已经运行，则只显示已有窗口，不会重复启动服务。

## 使用

1. 启动剪蛋，确认状态显示“已开启”。
2. 打开剪映草稿并停留在“素材”页面。
3. 截图或复制一张图片。
4. 切回剪映并按 `Ctrl+V`。
5. 图片会进入素材区，并自动选中和预览。

关闭窗口只会隐藏到系统托盘。需要完全退出时，右键托盘图标并选择“退出”。

## 项目结构

```text
jy_live_paste/      主程序
assets/brand/       透明底品牌图标
tests/              自动测试
run.bat             Windows 启动入口
requirements.txt    运行依赖
```

运行过程中，导入的图片会保存在 `a/<随机ID>/i.png`。这些文件可能被剪映草稿引用，请不要在仍需使用对应草稿时删除。运行日志写入 `import-debug.log`。

## 开发与测试

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m pytest -q
```

当前自动测试覆盖剪贴板安全、剪映前台判断、导入契约、窗口路由和视觉检测逻辑。

## 工作原理

剪蛋按条件注册 `Ctrl+V`：只有剪映处于前台且剪贴板包含图片时才接管快捷键。图片先保存到独立短路径，再调用剪映原生导入流程；系统文件选择窗口在显示阶段被设为不可见且不可激活，随后只提交本次图片的精确路径。文字剪贴板和其他应用中的粘贴保持系统原行为。
